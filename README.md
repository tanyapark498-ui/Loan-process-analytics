# Loan Process Analytics

Разобрала процесс выдачи кредитов по данным голландского банка, чтобы найти задержки и понять, на каких этапах теряются клиенты.

## Данные

BPI Challenge 2017 — открытый лог кредитных заявок за 2016–2017 годы.

31 509 заявок

1,2 млн событий

## Что сделала

Проанализировала процесс с помощью Process Mining (pm4py).

Изучила длительность заявок и время прохождения отдельных этапов.

Построила воронку по работе с кредитными предложениями.

Сравнила запрошенные и предложенные суммы.

Подготовила схемы процесса AS-IS и TO-BE в BPMN.

## Что получилось

Срок обработки: медиана — 19 дней, среднее — 22 дня. Треть заявок обрабатывается дольше 31 дня.

Конверсия офферов: 54,7% предложений принимаются клиентами.

Проверка документов: занимает в среднем 9,9 дня.

Ожидание ответа клиента: в среднем 13,8 дня.

Потери: часть предложений автоматически отменяется через 30 дней без ответа.

## AS-IS → TO-BE

| | AS-IS | TO-BE |
|---|---|---|
| Валидация документов | Ручная, 9.9 дней | Автоматическая, цель 2 дня |
| Напоминания клиенту | Нет | 7-й, 14-й, 21-й день |
| Срок автоотмены | 30 дней | 21 день |
